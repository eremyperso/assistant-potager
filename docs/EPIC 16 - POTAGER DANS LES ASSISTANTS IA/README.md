# ÉPIC 16 — Potager dans les assistants IA (MCP)

> Numéro d'épic à valider (D8 de l'étude).

Brancher le potager dans Claude, ChatGPT ou Le Chat (Mistral) par un serveur MCP distant :
consulter, analyser, enregistrer des gestes depuis l'assistant que le jardinier utilise déjà.
Un **canal de plus**, pas un remplaçant du compagnon.
